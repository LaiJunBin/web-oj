# Web-OJ

A self-hosted Online Judge platform for evaluating web-based projects, designed for skill competitions.

## Status

> This project is part of a master's thesis at National Yang Ming Chiao Tung University (NYCU).

This repository is currently reserved. The source code will be released after the competition concludes.

本系統為碩士論文之研究成果，原始碼將於實際競賽結束後正式對外公開。

一方面，本論文繳交時程早於競賽舉辦時間，賽前系統仍可能持續依競賽需求調整與優化；另一方面，全國技能競賽亦作為本研究最終的實驗驗證場域，待競賽完整執行並於實務場域中驗證系統運作成效後，方能確認系統的實際運作成效與穩定性，並視需求進行賽後的功能微調與優化。基於上述考量，選擇於競賽結束並完成必要調整後再行釋出，以確保開源版本能完整呈現經過實際驗證且趨於穩定的最終成果，屆時將開源於此 Repository，並附上詳細的使用說明與相關文件，以供有興趣導入本系統的教育單位、競賽主辦方及開發社群參考與使用。
